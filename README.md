# 🫧또또SFW

전연령 롤플레이용 장면 연속성 확장이에요. 또또NSFW의 자매 확장이지만 성적인 내용을 다루지 않고, 로맨스·갈등·일상 등 어떤 장르의 장면에도 쓸 수 있게 만들었어요. NSFW판과 동시에 설치해도 저장 키·상태 태그·설정 화면이 전부 분리돼 있어서 충돌하지 않아요.

## 핵심 기능

- **직전 전개 반복 금지** — 같은 행동·전개가 말만 바뀌어 계속 나오는 것을 막아요
- **대사 전개 반복 금지** — 같은 질문·부탁·칭찬·도발 같은 대사의 목적이 말만 바뀌어 계속 나오는 것을 막아요
- **상태 연속성 추적** — 장소·인물의 외형/자세/소지품이 응답마다 제멋대로 바뀌거나 리셋되는 것을 막아요
- **진도 관리(슬로우번)** — 같은 자리를 맴돌다 장면이 흐지부지 끝나거나, 반대로 너무 급하게 전개되는 것을 막아요
- **다음 전개 힌트** — AI가 제안한 다음 전개 후보를 다음 생성에 힌트로 다시 넣어줘요

## 동작 개요

1. 매 생성마다 프롬프트에 "현재 장면 상태 + 최근 전개(반복 금지) + 상태 태그 갱신 지시"를 주입해요.
2. AI 응답 끝의 `<sfw_scene>{...}</sfw_scene>` 태그를 파싱해서 메시지에 저장하고, 화면에 보이는 본문에서는 지워요.
3. 태그가 누락되면(또는 수동 버튼을 누르면) 보조 AI 호출로 최근 대화를 분석해 상태를 보정해요.

## 개입 방식

또또NSFW와 달리 별도의 "성인 캐릭터 확인" 절차가 없고, 개발자 모드도 없어요. 설정에 있는 기능이 전부예요.

- **상시 개입 (기본값)**: 채팅별 사용 토글을 켜면 그 즉시 전체 기능이 항상 동작해요. 평범한 일상 RP에서도 계속 상태를 추적하고 반복을 막아주길 원한다면 이 방식을 추천해요.
- **강도 자동**: 평소엔 장면의 서사적 강도(0~10) 한 줄만 요청하는 초경량 감시만 하다가, 강도가 5 이상으로 올라가면 자동으로 전체 기능을 켜고, 2 이하로 내려가면 다시 감시만 하는 상태로 돌아가요. 갈등이 고조되거나 감정이 절정에 이르는 장면에만 개입을 집중시키고 싶을 때 써요.

"지금 개입" 버튼으로 언제든 직접 켜고 끌 수 있어요.

## 💬 대사 전개 반복 방지

전개(행위) 반복 금지와 별개로, 캐릭터가 **대사로 하는 일**이 반복되는 것도 막아줘요. 모델이 상태 태그에 `dialogue_beats`(예: "같은 부탁 반복", "같은 칭찬", "확인 질문")를 적어주면, 최근 N개 AI 답변에서 쓴 의도를 "말만 바꿔서 반복하지 마" 목록으로 주입해요.

- 문장 표현이 아니라 **대사의 목적**을 막아요.
- 범위는 설정에서 1~6개 답변으로 조절 (기본 2).
- 태그에 `dialogue_beats`가 빠져도 그것 때문에 보조 AI 호출이 나가진 않아요.

## 🔥 슬로우번

행동 하나를 반복시키는 게 아니라, 6단계(긴장과 분위기 → 시선·말·거리 좁히기 → 첫 의미 있는 교류 → 관계·반응 심화 → 전환점·고조 → 해소·결말 허용)로 장면의 진행도를 추적해요. 로맨스의 밀당이든, 화해로 가는 갈등이든, 대치 상황의 고조든 어떤 아크에도 쓸 수 있어요.

**내가 유지하고 싶은 장면**을 직접 입력하고 진행 횟수를 정하면, 그 장면을 정확히 그 횟수만큼 유지하도록 AI에게 강하게 지시해요. 예: "화해" 장면을 3회 유지 — 그 사이엔 장면이 조기 종료되거나 다른 장면으로 넘어가지 않아요.

## 🧩 CardInject 연동 (선택 기능)

CardInject 확장으로 분석해둔 캐시트 카테고리 중 고른 것을 **다음 전개 힌트의 참고 자료**로 써요.

- 설정 → **🧩 CardInject 연동**을 켜고, 목록에서 참고시킬 카테고리를 체크하세요.
- **개입 중일 때만** 주입돼요. 평소(감시 대기)엔 아무것도 안 들어가요.
- 다음 전개 힌트가 켜져 있어야 동작해요.
- 참고 자료일 뿐이에요. "강요하지 말 것, 현재 장면 상태·하드 리밋·유저 금지를 어기지 말 것"이 같이 붙어요.
- 보조 AI 보정 호출도 캐시트를 못 보기 때문에, 보정할 때도 같은 참고 자료를 같이 넘겨서 `next` 제안에 반영시켜요.
- CardInject에서도 켜져 있는 카테고리를 고르면 프롬프트에 두 번 들어가요. CardInject에서 그 카테고리를 끄면(내용은 남아 있음) 이 확장이 개입 중일 때만 주입하는 식으로 쓸 수 있어요.

## 장면 상태 탭

- **장소 / 인물별 외형·자세·소지품**: 직접 수정 가능
- **최근 전개**: ×로 반복 금지 목록에서 제외 가능
- **최근 대사 전개**: 대사 반복 방지가 켜져 있을 때, 최근 쓴 대사 의도 목록
- **다음 전개 후보**: AI가 제안한 새 전개. ×로 제안에서 제외 가능
- **주입문 보기**: 실제로 AI에게 들어가는 지시문을 글자 수·토큰 수와 함께 그대로 확인 가능 (버튼 바로 아래에 펼쳐져요)

## 설정 요약

- 반복 금지 범위·최대 개수, 대사 반복 금지 범위
- 진행 속도(자동/유지/느리게/빠르게), 슬로우번 켜기·강도, 사용자 주도 전개 허용
- 장면 응답 길이·묘사 밸런스(대사/감각/심리 위주)
- 전역 하드 리밋(모든 채팅 공통 금지 목록)
- 해제 브릿지(개입이 꺼진 직후 한 번만 자연스러운 마무리 지시)
- 태그 누락 시 자동 보정 + 전용 연결 프로필

## NSFW판과 같이 써도 되나요?

네. 저장 키(`ttottoSfw`)·상태 태그(`<sfw_scene>`)·인터셉터 함수·CSS/DOM 프리픽스(`tsf-`)가 또또NSFW(`ttottoNsfw` / `<sfw_scene>`이 아닌 별도 태그 / `tns-`)와 전부 분리돼 있어서, 같은 채팅에 두 확장을 동시에 켜둬도 서로의 상태 태그를 건드리지 않아요. 다만 같은 채팅에서 둘 다 개입 중이면 지시문이 두 배로 들어가니, 보통은 채팅·캐릭터별로 하나만 켜두는 걸 추천해요.
